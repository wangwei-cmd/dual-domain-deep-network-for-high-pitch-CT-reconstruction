# dual-domain-deep-network-for-high-pitch-CT-reconstruction
Codes for the paper "A dual-domain deep network for high pitch CT reconstruction" https://www.sciencedirect.com/science/article/abs/pii/S0031320324009841》

Run the scripts  recon_64_geomety_1.m, recon_24_geomety_1.m and mergedata_24.m in the data subfolder  to generate the training and test data.

Run the script recon_64_geometry_1_para.m to generate the parameters for the reconstructing algorithm.

Run the script fast_pitch_unet3d_24.py to train our network.

Run the script test_fast_pitch_unet3d.py to test our network.
